# Console Task Manager

Консольное приложение для эффективного управления списком задач, написанное на чистом Python без использования сторонних библиотек.

## Возможности

- **Управление задачами:** Создание, просмотр, завершение и удаление задач.
- **Приоритеты:** Установка приоритетов для задач (`High`, `Medium`, `Low`) с возможностью фильтрации.
- **Даты и дедлайны:** Автоматическая фиксация времени создания задачи и поддержка опциональных дедлайнов (с проверкой просроченных задач).
- **Сортировка:** Гибкая сортировка списка по ID, названию, статусу выполнения или дате создания.
- **Поиск:** Регистронезависимый поиск задач по названию.
- **Статистика:** Подсчет общего количества задач, выполненных, невыполненных и расчет процента выполнения.
- **Сохранение данных:** Автоматическая персистентность данных в формате JSON (`tasks.json`).
- **Безопасность ввода:** Защита от сбоев при некорректном вводе пользователя и повреждении файла данных.

---

## Запуск

python main.py
