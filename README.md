# Task Manager
Простой, надежный и удобный консольный менеджер задач, 
написанный на Python. Проект поддерживает сохранение 
данных в формате JSON, фильтрацию ввода, поиск задач 
и просмотр статистики выполнения.
## Возможности
- создание задач;
- просмотр задач;
- завершение задач;
- удаление;
- поиск;
- статистика;
- сохранение в JSON.
## Запуск
python main.py
